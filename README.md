# Register & Login — Week 1 Case

Setup and run
```bash
git clone https://github.com/Dbinus/Aksub-Week1-FE.git
npm install
npm run dev
```

Buka browser `http://localhost:5173`

### Penjelasan singkat

- Menggunakan Vite

- Data disimpan di sessionStorage menggunakan array of objects

- Menggunakan filter untuk email login, find untuk mencari existing user di register, dan map untuk menambah user baru ke sessionStorage

- ~Design sebisa mungkin mengikuti figma (tidak sama persis), menggunakan card bukan tanpa card/background putih~

- `Card sudah di-comment, kalau mau pakai card -> uncomment bagian card + variable --bg di bagian :root dalam ./src/style.css`
